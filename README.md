# Муҳимтарин мавзӯъҳо дар JavaScript

## 1. Scope (Ҳудуд)
Дар JavaScript, "Scope" (ҳудуд) маънои муҳити ҷории коди шуморо дорад. Ин муҳит муайян мекунад, ки кадом тағйирёбандаҳо ва функсияҳоро метавон дастрас кард. Ба таври дигар, ҷои эълони тағйирёбанда ё функсия дар JavaScript муайян мекунад, ки ба он дар куҷо дастрасӣ дошта метавонед.

Навъҳои ҳудуд:
- **Global Scope (Ҳудуди умумӣ)**
- **Local Scope (Ҳудуди маҳаллӣ):**
  - **Function Scope (Ҳудуди функсия)**
  - **Block Scope (Ҳудуди блок)**
- **Module Scope (Ҳудуди модул)**

## 2. Hoisting (Бардоштан)
Hoisting мафҳумест дар JavaScript, ки тағйирёбандаҳо ва функсияҳоро ба боло мебарад. Ин маънои онро дорад, ки эълони функсияҳо ва тағйирёбандаҳо қабл аз иҷрои код дар боло ҷойгир карда мешаванд. Аммо, танҳо эълони онҳо мебардорад, на таъини арзиши онҳо.

Мисол:
```js
console.log(x); // undefined
var x = 5;
```
Дар ин ҷо, тағйирёбандаи `x` эълон шудааст, аммо то таъини арзишаш `undefined` мебошад.

## 3. TDZ (Минтақаи муваққатии дастнорасӣ)
TDZ (Temporal Dead Zone) ҳолатест, ки тағйирёбандаҳо вуҷуд доранд, аммо то эълони онҳо наметавонанд истифода шаванд. Тағйирёбандаҳои `let` ва `const` дар TDZ аз ибтидои ҳудуди худ то эълон шудани онҳо мавҷуданд, аммо дастрасӣ надоранд.

### Чӣ тавр TDZ-ро пешгирӣ кардан мумкин аст?
Барои пешгирӣ кардани TDZ, ҳамеша тағйирёбандаҳои `let` ва `const`-ро дар аввали ҳудуди худ таъриф кунед.

Мисол:
```js
console.log(pi); // ReferenceError
const pi = 3.14;
console.log(pi); // 3.14
```
